# ERP Usaha

Demo aplikasi ERP berbasis web untuk perusahaan (PT/CV) dan UMKM: kasir & stok, pelanggan, unit usaha & jasa, biaya, jurnal otomatis, laba rugi, dan neraca.

Semua angka adalah data contoh (PT Maju Bersama, perusahaan fiktif). Data yang dicoba tersimpan di browser masing-masing pengguna.

Akun demo: direktur / direktur123 · keuangan / keuangan123 · kasir / kasir123
